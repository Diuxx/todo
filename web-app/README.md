# Todo Web App

Todo is the Angular and Capacitor application for the local-first Todo organizer, supporting browser and Android usage.

## Features

- Todo items, recurring subtasks, notes and quotations.
- Calendar navigation, completion history and budget views.
- Local notifications on supported Android devices.
- Local data storage and JSON backup/restore.
- Personal password for protected actions and item access.

## Quick Start

```bash
npm install
npm run start
```

The development server uses `http://localhost:4973`.
